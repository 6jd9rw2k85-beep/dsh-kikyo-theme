## 3. 中文长版（论坛 / 即刻 / 小红书 / 少数派）

```
【桔梗主题 · DSH Desktop】开源了

给 DeepSeek Harness 桌面版做的一层和风皮肤：开机十几秒的桔梗动画、动态壁纸、Q 版小桔梗、入场字幕配以原版日文旁白。

技术上比较有意思的几点：

· 开机动画不是程序化画的，是本机 ComfyUI 跑的 HunyuanVideo 1.5 图生视频（1280×704 / 49 帧），一条约 9 分钟。为了循环不跳帧，正放+倒放拼成 ping-pong，循环点就是一次普通帧步。
· 壁纸一开始用 canvas 逐帧重绘视频，结果"隔几秒抽一下" —— 换成原生 <video> + CSS filter 之后彻底好了。
· 所有遮罩都有纯 CSS 定时自撤 + JS 硬兜底。因为这个东西挂在界面最顶层，卡住的表现就是"应用打不开"，我被自己坑过两次。
· DPR 上限压到 1.5、默认关掉第二层粒子画布：好看不能换卡顿。

已知没解决的问题写在 README 里了：循环视频的"反向点"、Q 版只有 CSS 变换、字体强依赖 macOS、没有 HMR。

代码 MIT。图片/音乐/角色版权不属于我，所以仓库里不包含素材，给了重新生成的脚本和说明 —— 你可以用自己有版权的图跑出同样的效果。
```

## 5. English（Reddit / Hacker News / X）

```
Show: A Kikyo-themed skin for DeepSeek Harness Desktop

I've been building a skin layer for DSH Desktop (a local AI harness app). It's a web plugin that injects CSS/JS and serves its own routes, so everything is plain web tech.

Interesting bits:
- Boot clip is a real image-to-video generation (HunyuanVideo 1.5, 1280x704, 49 frames, ~9 min per clip) looped with ping-pong concatenation so the loop point is just a normal frame step.
- The wallpaper used to redraw a video through canvas every frame — that caused visible stutter. Switching to a native <video> element + CSS filters fixed it completely.
- Every overlay has a pure-CSS timed self-dismiss plus a JS hard fallback, because a stuck overlay means "the app won't open".
- Hard performance budget: DPR capped at 1.5, second particle canvas disabled by default.

Repo (code MIT, art assets deliberately excluded for copyright reasons): <link>
Open problems listed in the README — loop "reverse point", CSS-only chibi animation, macOS-only font stack, no HMR.
```
